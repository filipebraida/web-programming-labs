# Rural Storys

Plataforma de publicação e compartilhamento de histórias que está sendo desenvolvida com a turma de Programação Web 2026-2.

## Instalação do Desenvolvimento

1 - Criar o `.env`

```console
cp .env.example .env
```

2 - Instalar as dependências

```console
pnpm install
```

3 - Gerar a chave da aplicação

```console
node ace generate:key
```

4 - Executar as migrações do banco SQLite

```console
node ace migration:run
```

## Execução

```console
pnpm dev
```
